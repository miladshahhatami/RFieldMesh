# RFieldMesh 1.0.0 enhancement implementation

## Architecture

`config/properties.py` is the authoritative registry for display metadata,
Abaqus keyword and column mapping, units, defaults, admissible intervals, and
value validation. Configuration, GUI, random streams, writer, verifier,
visualization, and manifests consume this registry rather than maintaining
five unrelated code paths.

The parser projects scalar `*Density`, isotropic `*Elastic`, and
`*Mohr Coulomb` rows into `MaterialDefinition`. The writer groups selected
properties by keyword, replaces only registered columns, streams elementwise
material clones to a temporary output, synchronizes the file, and publishes it
atomically. Independent reparsing verifies target coverage, material names,
selected values, unselected source values, and output checksum before the
manifest is written.

Structured 2D exponential fields retain the Fourier method. Normal and
lognormal variables use the established rectangular Gaussian averaging by
default; bounded truncated-normal variables use normalized centroid sampling.
General coordinates use dense KL only inside the dense workspace budget and a
matrix-free pivoted covariance factor otherwise. A prepared spectral or
covariance factor is reused among variables with identical correlation and
algorithm settings; independent property-specific random streams are then
sampled from it.

## Principal modified files

| File | Purpose |
|---|---|
| `src/rfieldmesh/config/enums.py` | Five stable property identifiers and legacy modulus alias |
| `src/rfieldmesh/config/properties.py` | Central registry and admissibility validation |
| `src/rfieldmesh/config/models.py` | Property-aware statistics validation and resource budgets |
| `src/rfieldmesh/random_fields/rng.py` | Stable streams for all five properties |
| `src/rfieldmesh/random_fields/covariance_kl.py` | Dense-memory estimate and matrix-free pivoted factor |
| `src/rfieldmesh/abaqus/model.py` | Parsed Mohr–Coulomb values and generic property access |
| `src/rfieldmesh/abaqus/parser.py` | Scalar `*Mohr Coulomb` parsing |
| `src/rfieldmesh/abaqus/writer.py` | Column-aware multi-property streamed writing |
| `src/rfieldmesh/abaqus/validation.py` | Selected and unselected property verification |
| `src/rfieldmesh/application/generate.py` | Five-field orchestration, factor reuse, provenance |
| `src/rfieldmesh/gui/main_window.py` | Five GUI property panels |
| `src/rfieldmesh/visualization/figures.py` | Registry labels, diagnostics, bounded preview sampling |
| `tests/test_five_property_support.py` | Property, preservation, rejection, compatibility tests |
| `tests/test_supplied_models.py` | Supplied 2D and 3D regression fixtures |

The package version remains `1.0.0`. No DOI or external repository state is
changed by this enhancement.
