# RFieldMesh 1.0.0 cohesion-enhancement validation

Validation was performed on Linux with Python 3.12.13 using the authoritative
source archive and the two user-supplied representative Abaqus models.

| Model and target | Eligible elements | Method | Runtime | Output size | Independent reparse |
|---|---:|---|---:|---:|---|
| `2D-Model.inp`, `Part-1/Set-1` | 20,000 | 2D spectral | 63.915 s | 7,847,581 bytes | Passed |
| `3D-Model.inp`, `Layered Soil Quarter/Layer1` | 10,032 | covariance/KL, matrix-free pivoted factor | 3.140 s | 7,684,962 bytes | Passed |

Both cases randomized Young's modulus, density, Poisson's ratio, friction
angle, dilation angle, and cohesion simultaneously. The verifier reparsed every
generated material, checked all six values, material and set names, section
coverage, checksums, and the 600-element `AC3D8R` remainder in the 3D case.

The source cohesion values were read as 5000 Pa for the 2D soil, and 15000,
20000, and 5000 model-consistent stress units for 3D Layers 1–3. The generated
cohesion minima were 955.5672988309543 (2D) and 10315.825593292371 (3D), both
within the required interval `c >= 0`.

The five legacy fields in each new manifest were compared directly with the
corresponding `all_five` manifest. Every element-value mapping was exactly
equal for all five properties, demonstrating that adding cohesion did not
alter existing streams.

The source-quality gate passed 98 tests with one GUI smoke skip, 72% aggregate
coverage, Ruff linting, Ruff formatting, strict mypy checking, and wheel/sdist
builds. The skipped GUI runtime test is attributable to the host's missing
`libEGL.so.1`; source-level GUI cohesion assertions remain in the suite.

A wheel installed into a separate virtual environment reported version 1.0.0,
recognized the cohesion keyword mapping, and passed CLI help and representative
2D inspection using the already validated dependency environment. A fully
offline dependency-resolving install could not be completed because dependency
wheels were not present in the local cache.

Neither a Windows executable nor a native Abaqus import, datacheck, or analysis
was run on this Linux host. The updated native validator and templates cover
all six properties, but their native execution remains a maintainer action.
