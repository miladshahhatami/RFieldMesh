# RFieldMesh 1.0.0 enhancement validation

Validation was performed on Linux with Python 3.12.13. Peak resident memory was
recorded with `resource.getrusage`; elapsed time used `time.perf_counter`.

| Model and target | Eligible elements | Method | Retained modes | Runtime | Peak RSS | Output size | Independent reparse |
|---|---:|---|---:|---:|---:|---:|---|
| `2D-Model.inp`, `Part-1/Set-1` | 20,000 | 2D spectral | n/a | 39.709 s | 557.43 MiB | 7.28 MiB | Passed |
| `3D-Model.inp`, `Layered Soil Quarter/Layer1` | 10,032 | Pivoted covariance | 70 | 2.226 s | 255.50 MiB | 7.23 MiB | Passed |

Both cases randomized Young's modulus, density, Poisson's ratio, friction
angle, and dilation angle simultaneously. The verifier reparsed every generated
material, checked exact target coverage and registered property values, checked
the output checksum, and preserved the 600 ineligible `AC3D8R` Layer 1 elements
through the source-material remainder assignment in the 3D case.

- 3D: `ff605ff694c03a1644285c465139ef6042290482baa7b15a74a22370f1747454`

Verified output checksums:

- 3D: `3c49546cf7aff129479a652b05e83c2e0d55dc7787d7da9b031f77636bf4ef87`

The final source test suite passed 82 tests; one GUI runtime smoke test was
skipped because the Linux host lacks `libEGL.so.1`.

Abaqus is not installed in this environment; therefore, native Abaqus/CAE
import, datacheck, and analysis were not claimed. Qt GUI runtime tests were
also unavailable because the host lacks `libEGL.so.1`. Source-level GUI
coverage, configuration tests, writer/reparser tests, and Windows packaging
configuration were retained. The Windows executable must be rebuilt and
smoke-tested on Windows using `packaging/windows/build.ps1`.
